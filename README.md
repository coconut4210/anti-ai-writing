# Anti-AI-Writing

一个用于“用户给出核心论点后进行独立创作”的中文写作 Skill。1.0 聚焦三类常见问题：稻草人、逻辑断裂和防御性写作。

它的目标不是把文本改成统一腔调，而是让文章保留用户真正的判断、沿可成立的论证路径推进，并避免为了显得全面而虚构反方或泄漏修改历史。

## 适用场景

- 用户给出观点，要求写评论、分析或论证；
- 希望从一个核心判断发展为独立成稿；
- 希望减少“不是……而是……”式防御、无依据级联推论和对原论点的偷换。

不自动用于翻译、摘要、排版、单纯事实核查、只诊断已有文章，以及不以核心论点为中心的创作。

## 安装

将本仓库根目录复制或链接到 Codex Skills 目录下，并保留目录名 `anti-ai-writing`。然后可显式调用：

```text
$anti-ai-writing 围绕这个观点写一篇评论：……
```

符合适用场景的请求也会自动触发。

## 用户控制

```text
不要使用 anti-ai-writing
关闭 anti-ai-writing
跳过防御性写作检查
只使用稻草人和逻辑断裂模块
```

## 1.0 模块

| 模块 | 作用 |
|---|---|
| 稻草人保护 | 保留用户论点的主体、范围、程度、条件和比较维度。 |
| 逻辑断裂控制 | 检查关键关系是否有依据，并要求段落真正推进论证。 |
| 防御性写作控制 | 删除无关反方与约束泄漏，区分预期机制和已被证实的实际效果。 |

当文章存在需要用户决定的证据缺口时，正文后会提供“网络调查搜集材料／我来补充／仅保留当前叙述／删除当前叙述”四个选项。
