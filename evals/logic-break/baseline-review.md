# 逻辑断裂无规则基线记录

规则版本：不加载 `02-逻辑断裂.txt`。

| 案例 | 是否触发预期失败 | 证据片段 | 备注 |
|---|---|---|---|
| LB-B01 | 是 | “推荐内容更贴近用户需求，能够减少寻找成本”以及“在一定程度上提高了用户满意度” | 材料只给出上线时间相邻和两个指标同时上升，模型自行补出推荐匹配机制，并据此支持满意度结论。结尾虽加限定，但前文已把未提供的机制写成事实。 |
| LB-B02 | 否 | “加班减少可能源于任务量下降……即使效率确实提升，也不能直接推断员工满意度上升” | 无规则模型主动阻断了多级推论，是需要保持的正例。 |
| LB-B03 | 否 | 各段依次讨论生活入口、便利机制、依赖风险和人与工具的关系 | 没有明显的换词复读，推进维度基本成立；出现的防御式句型属于03范围，不计作02失败。 |
| LB-B04 | 否 | “像一块始终压在胸口的阴影”“仿佛情绪被困在……” | 主观归属清楚，解释建立在用户给出的低音、高音观察上，没有伪称作曲者意图。 |

## 基线结论

1. LB-B01复现了02所针对的关系断裂：模型会为保留用户结论而补写材料中不存在的机制。
2. LB-B02表明模型有时能够自行阻断级联，加载规则后不能退化成机械维护原结论。
3. LB-B03与LB-B04分别作为推进正例和主观解释边界例，用来检查误报与误删。
