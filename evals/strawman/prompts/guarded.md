# 加入稻草人预防规则的创作提示

请根据下面提供的核心论点，完成一篇 600—900 字的中文探讨性文章。

文章应当围绕论点展开，解释其理由、适用边界和可能的不同意见。不要向用户提问，不要引用未经提供或无法确认的具体数据、人物言论和研究结论。直接输出文章正文，不说明写作过程。

创作时遵守以下约束：

1. 准确保留核心论点的主体、范围、程度、条件、比较维度和不确定性，不把推测的意图或隐含立场归给用户。
2. 可以分析最强合理异议，但异议必须针对核心论点的真实强版本。不得通过绝对化、扩大范围、删除条件、改变概率或偷换比较维度来制造更容易反驳的版本。
3. 作者主动引入的异议必须明确标记为外部观点或分析角度，不能写成对用户的纠正。
4. 不强制正反对称，只保留能够推进核心论点的异议、条件和变量。
5. 完稿前检查所有被反驳的命题：它们要么由核心论点明确提出，要么被清楚标记为作者主动引入的异议。
