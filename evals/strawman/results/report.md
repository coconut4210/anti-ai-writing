# 稻草人预防规则首轮 A/B 测试报告

## 结论

当前预防规则未通过首轮试点。普通创作基线 A 和规则版 B 的六篇文章都出现了至少一处稻草人硬失败；规则版没有降低失败率，也没有提高综合评分。

本轮结果不能支持“现有规则能够在创作阶段避免稻草人”的结论。

## 方法

- 日期：2026-10-09
- 模型：`gpt-5.6-sol`
- 推理设置：`medium`
- 测试论点：6 条，覆盖程度、优先级、条件、概率、局部批评和价值排序
- 变体：普通创作提示 A；加入稻草人预防规则的提示 B
- 原始文章：12 篇，全部由相互隔离、无历史上下文的运行生成
- 评审：2 位独立盲评员
- 盲法：评审只看到随机编号、核心论点和评分标准，不知道 A/B 映射
- 评审一致性：24 次文章评分均判为硬失败，硬失败判断无分歧

## 汇总结果

| 指标 | A：普通创作 | B：规则版 |
|---|---:|---:|
| 文章数 | 6 | 6 |
| 两位评审一致判定硬失败 | 6/6 | 6/6 |
| 硬失败评次 | 12/12 | 12/12 |
| 平均总分（满分 10） | 6.08 | 6.00 |

| 异议归属均分 | 0.00 | 0.00 |
| 核心论点推进均分 | 2.00 | 2.00 |

所有 24 次评分都将严重程度判为“轻度”：文章仍然充分推进了核心论点，但局部加入了用户没有提出的更强命题，再对其进行否定或澄清。

## 主要失败模式

六类论点在 A、B 两版中都出现了同一种结构：

1. 用户提出带有限定的论点 P。
2. 文章构造更强、更绝对的 P′。
3. 文章使用“并不意味着”“并不等于”“并不是说”等结构否定 P′。
4. P′ 没有被标记为作者主动引入的异议，却以澄清原论点的方式出现。

典型证据：

| 用例 | A：普通创作 | B：规则版 |
|---|---|---|
| 程度判断 | “完全拒绝教程并不明智。” | “这一论点并不意味着教程没有价值……” |
| 优先级 | “‘优先’并不等于只考虑既有居民……” | “‘优先’并不意味着所有资源都只能用于修缮住宅……” |
| 条件判断 | “‘轻量’并不等于没有计划、没有分工。” | “关键并不是‘小团队天然排斥管理’……” |
| 概率判断 | “这并不意味着公开量化信息必然有害。” | “并不是‘量化必然有害’，也不是‘排名永远不该公开’。” |
| 局部批评 | “问题并不在于远程办公天然排斥新人。” | “‘缺陷’并不意味着远程办公必然不利于所有新人……” |
| 价值排序 | “这并不是说效率不重要。” | “这并不意味着效率无关紧要。” |

## 对现有规则的判断

现有规则正确描述了原则，但对生成行为的约束不够具体。模型能够做到：

- 保留并推进核心论点；
- 提出合理异议；
- 在部分段落中明确标记“外部异议”。

但模型仍把防御性澄清视为正常的边界说明，没有把其中被否定的命题视为需要检查归属的反驳对象。因此，“外部异议要标记来源”和“完稿前检查所有被反驳命题”尚未转化成稳定行为。

## 建议修订

下一版规则需要增加可直接执行的检查，而不是继续补充抽象原则：

1. 把否定式澄清纳入反驳命题检查。“不意味着 X”“并不等于 X”“并不是说 X”“不能因为 P 就 X”中的 X，都必须被视为被反驳命题。
2. 若 X 不是用户明确提出的内容，不得用纠正或澄清用户的语气引入。
3. 优先用肯定式边界说明替代虚构反方。例如将“这并不意味着教程无用”改为“教程适合建立概念框架，项目实践更侧重能力转化”。
4. 如果 X 确实值得讨论，应明确写成“一个可能的外部异议是 X”，并解释它与原论点的关系。
5. 完稿校验时扫描高风险结构，将它们作为复核触发器，而不是仅凭词语直接判错。
6. 修订后使用相同六条论点运行 C 版，与已保存的 A、B 结果比较；不得修改首轮原始输出。

## 限制

- 只有一个模型和一次采样，不能推断跨模型稳定性。
- 样本均为人工构造的通用论点，尚未覆盖用户真实长论点。
- 两位评审对硬失败完全一致，但综合分数存在尺度差异。
- 本轮只测试稻草人，不代表其他问题规则有效。
